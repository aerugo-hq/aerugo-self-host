# payments-knowledge

Curated knowledge for the payments team, in Open Knowledge Format (OKF v0.2) with the knowledge-layer
`x-kl` profile. Every concept needs a unique `x-kl.id`. Pull requests run knowledge CI
(`.github/workflows/knowledge-ci.yml`); merges to `main` are indexed by knowledge-layer, pinned to the
merge commit, and readable only by people GitHub lets read this repo, narrowed further by each
concept's `x-kl.audience`.

`index.md` and `log.md` are reserved OKF files, so this page isn't indexed as a concept.
